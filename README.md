# ⏱️ TimeTrack — מעקב זמן גלישה חכם

תוסף Chrome מודרני למעקב אחר כמות הזמן שאתם מבלים באתרים — חלופה פרטית
ומקומית ל-Webtime Tracker, עם פילוח מעמיק, יעדים, גיבוי בענן וייצוא נתונים.

> כל הנתונים נשמרים **מקומית** במחשב שלכם. שום דבר לא נשלח לאף שרת אלא אם
> תפעילו במפורש גיבוי בענן.

## ✨ תכונות

- **מעקב אוטומטי וחכם** — סופר רק זמן *פעיל*: כשהחלון בפוקוס ואתם לא במצב
  חוסר-פעילות. אפשרות להמשיך לספור כשמתנגן אודיו ברקע.
- **עיצוב מודרני** — ממשק כהה/בהיר/אוטומטי, RTL מלא, גרפים חלקים.
- **לוח בקרה עשיר** עם 4 לשוניות:
  - **סקירה כללית** — כרטיסי סיכום (היום / טווח / ממוצע / ציון פוקוס / רצף),
    גרף מגמה לאורך זמן, פילוח קטגוריות ואתרים מובילים.
  - **אתרים** — טבלה הניתנת לחיפוש ומיון, עם זמן, ביקורים, אחוז ומגבלה לכל אתר.
  - **תובנות חכמות** — מפת חום של ימים×שעות, התפלגות שעתית, זמן פרודוקטיבי מול
    מסיח, והשעה הפעילה ביותר.
  - **הגדרות** — שליטה מלאה.
- **קטגוריות חכמות** — סיווג אוטומטי של אתרים (פרודוקטיביות, רשתות חברתיות,
  בידור, חדשות ועוד) + **ציון פוקוס 0–100**. ניתן לערוך כל סיווג.
- **מצב פוקוס (Pomodoro)** — סבבי עבודה→הפסקה שחוסמים אתרים מסיחים, עם מצב "רשימת
  היתר" (חסום הכל חוץ מהמותר) וקיצורי מקלדת (Alt+Shift+F).
- **תובנות אוטומטיות** — "רשתות חברתיות +30% מהשבוע שעבר", היום העמוס ביותר ועוד.
- **ייבוא CSV ואייקוני אתרים אמיתיים (אופציונלי)** — מסלול הגירה ממעקבים אחרים.
- **יעדים ומגבלות** — מגבלת זמן יומית, מגבלה לכל אתר, יעד יומי ושבועי, עם התראות
  וסיכום שבועי אוטומטי.
- **השוואת תקופות ופירוט אתר** — השבוע מול שבוע שעבר, ולחיצה על אתר פותחת ציר זמן.
- **טווח תאריכים מותאם** — בנוסף לטווחים המהירים (היום / 7 / 30 / 90 / הכל).
- **גיבוי בענן מוצפן** — סנכרון ל-Google או שרת מותאם (HTTPS), עם הצפנת AES-256
  אופציונלית בסיסמה (zero-knowledge).
- **ייצוא/ייבוא** — JSON (גיבוי מלא) ו-CSV (הכל או התצוגה הנוכחית).
- **דו-לשוני** — ממשק עברית/אנגלית עם החלפה חיה.
- **פרטיות** — ללא הרשאות host, ללא מעקב חיצוני, ללא קריאות רשת לא-רצוניות
  (אייקונים נוצרים מקומית), מחיקה אוטומטית של נתונים ישנים.

## 🚀 התקנה

מכיוון שהתוסף אינו בחנות, מתקינים אותו במצב מפתח:

1. פותחים את `chrome://extensions`
2. מפעילים **מצב מפתח** (Developer mode) בפינה הימנית העליונה
3. לוחצים **טען תוסף לא ארוז** (Load unpacked)
4. בוחרים את תיקיית **`extension/`** (זו התיקייה הנטענת/מועלית לחנות)
5. מצמידים את התוסף לסרגל הכלים — ומתחילים לגלוש 🎉

לחיצה על האייקון פותחת חלון מהיר; הכפתור "פתח לוח בקרה מלא" פותח את לוח הבקרה.

## ☁️ הגדרת גיבוי בענן

- **Google Sync** — מפעילים את "סנכרון לחשבון Google" בהגדרות. הנתונים מגובים
  אוטומטית דרך מנגנון הסנכרון של Chrome (מוגבל ל-~100KB; ימים ישנים נחתכים אם
  צריך, אך הנתונים המקומיים נשארים מלאים).
- **שרת מותאם אישית** — מזינים כתובת URL (ו-token אופציונלי) של נקודת קצה שאתם
  שולטים בה; התוסף ישלח אליה את הגיבוי המלא ב-`POST`.
- **קובץ** — תמיד אפשר לייצא JSON/CSV ידנית ולשמור היכן שתרצו.

## 🔧 פיתוח

ללא שלב build וללא תלויות — JavaScript מודולרי טהור. הבדיקות (42 מקרים) רצות מ-
`store-assets/dev`:

```bash
cd store-assets/dev
npm test               # node --test (ללא תלויות חיצוניות)
pwsh build.ps1         # יוצר zip להעלאה מתוך extension/
```

לפרטי ארכיטקטורה, מודל הנתונים ומפת הקבצים ראו **[CLAUDE.md](CLAUDE.md)**.

## 📁 מבנה

```
extension/               ← ההפצה (טוענים/מעלים לחנות את התיקייה הזו)
  manifest.json          — הגדרות התוסף (MV3)
  background.js          — מנוע המעקב (service worker)
  src/lib/               — לוגיקה משותפת (storage, stats, charts, backup, crypto, i18n)
  src/popup/             — החלון המהיר
  src/dashboard/         — לוח הבקרה המלא
  src/blocked/           — דף חסימה למצב פוקוס
  icons/                 — אייקונים
store-assets/            ← נכסים לחנות: מדיניות פרטיות, טקסט רישום, תמונות, בדיקות
```

## 🔒 הרשאות ולמה הן נחוצות

| הרשאה | שימוש |
|-------|-------|
| `storage` / `unlimitedStorage` | שמירת נתוני הזמן וההגדרות מקומית |
| `tabs` | זיהוי הדומיין של הלשונית הפעילה |
| `idle` | הפסקת ספירה כשאתם לא פעילים |
| `alarms` | שמירה תקופתית וגיבוי אוטומטי |
| `notifications` | התראות על מגבלות זמן |

אין הרשאת `host` ואין גישה לתוכן הדפים — רק לכתובת הדומיין.
