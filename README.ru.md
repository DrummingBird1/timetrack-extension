# TimeTrack — трекер времени в браузере с приоритетом приватности

Современное расширение для Chrome, которое измеряет активное время, проведённое на каждом сайте — приватная и локальная альтернатива Webtime Tracker с глубокой аналитикой, целями, облачным резервным копированием и экспортом данных.

**[🌐 Сайт](https://drummingbird1.github.io/timetrack-extension/)** · **[📋 Журнал изменений](CHANGELOG.md)** · **[🔒 Политика конфиденциальности](store-assets/PRIVACY.md)**

> Все данные остаются **локальными** на вашем устройстве. Ничего никуда не отправляется, если вы явно не включите облачное резервное копирование.

## ✨ Возможности

- **Умное автоматическое отслеживание** — учитывается только *активное* время: окно в фокусе, и вы не бездействуете. Опционально можно продолжать учёт при фоновом воспроизведении звука.
- **Современный дизайн** — тёмная/светлая/автоматическая темы, полная поддержка RTL, плавные графики собственной разработки.
- **Насыщенная панель управления** с 4 вкладками:
  - **Обзор** — карточки сводки (сегодня / период / среднее / оценка фокусировки / серия дней), график тренда во времени, разбивка по категориям и топ сайтов.
  - **Сайты** — таблица с поиском и сортировкой: время, визиты, доля и лимит для каждого сайта; можно **закреплять** сайты сверху и искать по **всей истории**, а не только по выбранному периоду.
  - **Умная аналитика** — тепловая карта «день недели × час», почасовое распределение, продуктивное и отвлекающее время, ваш самый загруженный час.
  - **Настройки** — полный контроль с **поиском по настройкам** для быстрого доступа к нужному пункту.
- **Умные категории** — автоматическая классификация сайтов (продуктивность, соцсети, развлечения, новости и другое) + **оценка фокусировки от 0 до 100**. Любую классификацию можно изменить.
- **Режим фокусировки (Pomodoro)** — циклы работа→перерыв, блокирующие отвлекающие сайты, режим «белого списка» (блокировать всё, кроме разрешённого), **длинные перерывы** через несколько циклов, блокировка/разрешение по **конкретному домену** (а не только по категории), и горячие клавиши (Alt+Shift+F).
- **Неотслеживаемые сайты** — список сайтов, которые никогда не учитываются; управляется из Настроек или прямо из детального просмотра сайта («Не отслеживать этот сайт»), где также можно **объединять историю между доменами** (например, при ребрендинге сайта) и видеть **первое/последнее посещение**.
- **Автоматические инсайты** — «Соцсети +30% по сравнению с прошлой неделей», ваш самый загруженный день и многое другое.
- **Импорт CSV и настоящие иконки сайтов (опционально)** — путь миграции с других трекеров.
- **Цели и лимиты** — дневной лимит времени, лимит по сайту, дневные и недельные цели, **предупреждение при достижении 80%** до основного оповещения о превышении лимита (с кнопкой отложить на 1 час прямо в уведомлении) и автоматическая еженедельная сводка.
- **Сравнение периодов и детали по сайту** — эта неделя против прошлой, а клик по сайту открывает дневную временную шкалу **плюс почасовую разбивку** (часы пиковой активности для этого сайта).
- **Произвольные диапазоны дат** — в дополнение к быстрым диапазонам (сегодня / 7 / 30 / 90 / всё время).
- **Зашифрованное облачное резервное копирование** — синхронизация с Google или собственным сервером (HTTPS), с опциональным шифрованием AES-256 по парольной фразе (принцип «нулевого разглашения», с **индикатором надёжности парольной фразы**) и **предпросмотром перед восстановлением** (диапазон дней, общее время, число сайтов) — восстановление никогда не будет «вслепую».
- **Экспорт/импорт** — JSON (полная резервная копия) и CSV (всё или только текущий вид).
- **Шесть языков** — иврит, английский, арабский, русский, испанский и французский, с мгновенным переключением.
- **Приватность** — без разрешений на хосты, без внешнего трекинга, без непроизвольных сетевых запросов (иконки генерируются локально), автоматическое удаление старых данных.

## 🚀 Установка

Пока расширение не появилось в Chrome Web Store, установите его в режиме разработчика:

1. Откройте `chrome://extensions`
2. Включите **режим разработчика** (в правом верхнем углу)
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку **`extension/`** (именно эта папка загружается локально и отправляется в магазин)
5. Закрепите расширение на панели инструментов — и начинайте пользоваться браузером 🎉

Клик по иконке открывает быстрое всплывающее окно; кнопка «Открыть полную панель управления» открывает панель управления.

## ☁️ Настройка облачного резервного копирования

- **Синхронизация с Google** — включите «Синхронизировать с аккаунтом Google» в Настройках. Данные резервируются автоматически через встроенный механизм синхронизации Chrome (ограничение ~100 КБ; при необходимости самые старые дни обрезаются, но ваши локальные данные остаются полными).
- **Собственный сервер** — укажите URL (и опционально токен) для контролируемого вами эндпоинта; расширение отправляет на него полную резервную копию методом `POST`.
- **Файл** — вы всегда можете вручную экспортировать JSON/CSV и сохранить его где угодно.

## 🔧 Разработка

Никакой сборки, никаких зависимостей — чистый модульный JavaScript. Набор тестов (74 теста) запускается из `dist`:

```bash
cd dist
npm test               # node --test (no external dependencies)
pwsh build.ps1          # builds the upload zip from extension/
```

Архитектуру, модель данных и полную карту файлов см. в **[CLAUDE.md](CLAUDE.md)**.

## 📁 Структура

```
extension/               ← the shippable extension (load/upload this folder)
  manifest.json          — extension config (MV3)
  background.js          — the tracking engine (service worker)
  src/lib/                — shared logic (storage, stats, charts, backup, crypto, i18n)
  src/popup/               — the quick popup
  src/dashboard/            — the full dashboard
  src/blocked/              — the focus-mode block page
  icons/                  — icons
store-assets/            ← store assets: privacy policy, listing copy, images
  site/                  — marketing website source (published to GitHub Pages)
dist/                    ← dev tooling: tests, package.json, build.ps1, and the built zip
archive/                 ← superseded assets (old images/build versions)
```

## 🔒 Разрешения и зачем они нужны

| Разрешение | Назначение |
|---|---|
| `storage` / `unlimitedStorage` | Локальное хранение данных о времени и настроек |
| `tabs` | Определение домена активной вкладки |
| `idle` | Приостановка учёта при вашем бездействии |
| `alarms` | Периодическое сохранение и автоматическое резервное копирование |
| `notifications` | Оповещения о лимитах времени |
| `favicon` (опционально) | Настоящие иконки сайтов из локального кэша Chrome — только при ручном включении |

Без разрешения `host` и без доступа к содержимому страниц — только доменное имя.
