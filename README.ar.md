# TimeTrack — متتبع لوقت التصفح يضع الخصوصية أولًا

إضافة Chrome حديثة تقيس مقدار الوقت الفعلي الذي تقضيه في كل موقع إلكتروني — بديل يراعي الخصوصية ويعمل محليًا أولًا لأداة Webtime Tracker، مع تحليلات متعمقة، وأهداف، ونسخ احتياطي سحابي، وتصدير للبيانات.

**[🌐 الموقع الإلكتروني](https://drummingbird1.github.io/timetrack-extension/)** · **[📋 سجل التغييرات](CHANGELOG.md)** · **[🔒 سياسة الخصوصية](store-assets/PRIVACY.md)**

> تبقى جميع البيانات **محليًا** على جهازك. لا يُرسَل أي شيء إلى أي مكان ما لم تُفعّل النسخ الاحتياطي السحابي صراحةً.

## ✨ الميزات

- **تتبع ذكي وتلقائي** — يحسب فقط الوقت *الفعلي*: عندما تكون النافذة نشطة ولست خاملًا. يمكن اختياريًا الاستمرار في العدّ أثناء تشغيل صوت في الخلفية.
- **تصميم عصري** — مظاهر داكن/فاتح/تلقائي، دعم كامل للكتابة من اليمين إلى اليسار (RTL)، ورسوم بيانية سلسة مصمَّمة يدويًا.
- **لوحة تحكم غنية** بأربعة تبويبات:
  - **نظرة عامة** — بطاقات ملخّصة (اليوم / النطاق الزمني / المتوسط / درجة التركيز / التتابع)، ورسم بياني للاتجاه عبر الزمن، وتوزيع حسب التصنيفات، وأكثر المواقع استخدامًا.
  - **المواقع** — جدول قابل للبحث والفرز يعرض الوقت، والزيارات، والنسبة، وحدًا لكل موقع؛ يمكنك **تثبيت** المواقع في الأعلى، والبحث في **كامل السجل**، وليس فقط في النطاق الزمني المحدد.
  - **رؤى ذكية** — خريطة حرارية ليوم الأسبوع × الساعة، وتوزيع بالساعة، والوقت المُنتِج مقابل المُشتِّت، وأكثر ساعاتك ازدحامًا.
  - **الإعدادات** — تحكّم كامل، مع **مربع بحث في الإعدادات** للعثور على أي شيء بسرعة.
- **تصنيفات ذكية** — تصنيف تلقائي للمواقع (إنتاجية، وسائل تواصل اجتماعي، ترفيه، أخبار، والمزيد) + **درجة تركيز من 0 إلى 100**. يمكن تعديل كل تصنيف.
- **وضع التركيز (بومودورو)** — دورات عمل ← استراحة تحظر المواقع المُشتِّتة، ووضع "قائمة السماح" (حظر كل شيء باستثناء ما تسمح به)، و**استراحات طويلة** كل عدة دورات، وحظر/سماح حسب **نطاق محدد** (وليس التصنيف فقط)، واختصارات لوحة المفاتيح (Alt+Shift+F).
- **المواقع غير المتتبَّعة** — قائمة بالمواقع التي لا تُحتسَب أبدًا، تُدار من الإعدادات أو مباشرةً من صفحة تفاصيل الموقع ("عدم تتبع هذا الموقع")، حيث يمكنك أيضًا **دمج السجل بين نطاقين** (مثلًا عند تغيير موقع لعلامته التجارية) ورؤية **تاريخ أول/آخر زيارة**.
- **رؤى تلقائية** — مثل "ارتفاع استخدام وسائل التواصل الاجتماعي بنسبة 30% عن الأسبوع الماضي"، وأكثر أيامك ازدحامًا، والمزيد.
- **استيراد CSV وأيقونات مواقع حقيقية (اختياري)** — مسار للانتقال من أدوات تتبع أخرى.
- **الأهداف والحدود** — حدّ زمني يومي، وحدّ لكل موقع، وأهداف يومية وأسبوعية، و**تنبيه عند الاقتراب من 80%** قبل تنبيه تجاوز الحد (مع زر تأجيل لمدة ساعة على الإشعار نفسه)، وملخص أسبوعي تلقائي.
- **مقارنة الفترات وتفاصيل الموقع** — هذا الأسبوع مقابل الأسبوع الماضي، والنقر على موقع يفتح خطًا زمنيًا يوميًا **بالإضافة إلى توزيع بالساعة** (ساعات الذروة لذلك الموقع).
- **نطاقات تاريخ مخصصة** — إلى جانب النطاقات السريعة (اليوم / 7 / 30 / 90 / الكل).
- **نسخ احتياطي سحابي مشفَّر** — مزامنة مع Google أو خادم مخصص (HTTPS)، مع تشفير اختياري بعبارة مرور AES-256 (بنظام "عدم المعرفة"، مع **مقياس لقوة عبارة المرور**)، و**معاينة قبل الاستعادة** (النطاق الزمني، إجمالي الوقت، عدد المواقع) حتى لا تستعيد بياناتك دون رؤية ما بداخلها.
- **تصدير/استيراد** — بصيغة JSON (نسخة احتياطية كاملة) وCSV (كل شيء، أو العرض الحالي فقط).
- **ست لغات** — العبرية، الإنجليزية، العربية، الروسية، الإسبانية، والفرنسية، مع تبديل فوري بينها.
- **الخصوصية** — بلا أذونات وصول للمواقع (host permissions)، وبلا تتبع خارجي، وبلا أي اتصالات شبكة غير مرغوبة (الأيقونات تُنشأ محليًا)، وحذف تلقائي للبيانات القديمة.
- **ميزانيات أسبوعية للتصنيفات** — حدّد سقف الوقت لكل تصنيف أسبوعيًا، مع أشرطة تقدّم في النظرة العامة وتنبيهات عند 80٪ و100٪.
- **تحليلات إضافية** — اتجاه أسبوعي لدرجة التركيز مع أفضل أسبوع، وسلسلة بلوغ الهدف، ومقارنة أي نطاقين زمنيين مع أكبر التغيّرات حسب الموقع.
- **جلسات تركيز أذكى** — بدء تلقائي حسب جدول، ووضع صارم بلا خروج مبكر، وخيار «إيقاف مؤقت لمدة 10 دقائق» في صفحة الحظر، وسجل للجلسات.
- **سجل زيارات اختياري** — متوقف افتراضيًا: يسجّل وقت بدء كل زيارة ومدتها لتعرف كم تدوم زياراتك لموقع ما. يبقى على جهازك.
- **مصمَّم للسجلات الكبيرة** — آلاف المواقع تظهر فورًا؛ حدّد عدة مواقع دفعة واحدة لتصنيفها أو تحديد حدٍّ لها أو تثبيتها أو إيقاف تتبعها.
- **استيراد CSV مرن وبيانات تجريبية** — استورد ملفات CSV من TimeTrack أو بنمط RescueTime، أو جرّب لوحة التحكم ببيانات تجريبية تُزال بنقرة واحدة.
- **سهل الوصول** — تنقّل بلوحة المفاتيح، وتسميات لقارئات الشاشة، وتباين نص بمستوى AA، يُفحص تلقائيًا بواسطة axe-core.

## 🚀 التثبيت

بما أن الإضافة لم تُنشر بعد على متجر Chrome الإلكتروني، يمكنك تثبيتها في وضع المطوّر:

1. افتح `chrome://extensions`
2. فعّل **وضع المطوّر** (في الزاوية العلوية اليمنى)
3. انقر على **تحميل غير مُعبأ (Load unpacked)**
4. اختر المجلد **`extension/`** (هذا هو المجلد الذي يُحمَّل/يُرفع إلى المتجر)
5. ثبّت الإضافة في شريط الأدوات — وابدأ التصفح 🎉

يؤدي النقر على الأيقونة إلى فتح نافذة منبثقة سريعة؛ ويفتح زر "فتح لوحة التحكم الكاملة" لوحة التحكم.

## ☁️ إعداد النسخ الاحتياطي السحابي

- **مزامنة Google** — فعّل "المزامنة مع حساب Google" في الإعدادات. تُنسَخ البيانات احتياطيًا تلقائيًا عبر آلية مزامنة Chrome نفسها (بحد أقصى ~100 كيلوبايت؛ تُحذف أقدم الأيام عند الحاجة، لكن بياناتك المحلية تبقى كاملة).
- **خادم مخصص** — أدخل عنوان URL (ورمزًا اختياريًا) لنقطة نهاية تتحكم بها؛ ترسل الإضافة النسخة الاحتياطية الكاملة إليه عبر طلب `POST`.
- **ملف** — يمكنك دائمًا تصدير JSON/CSV يدويًا وحفظه أينما شئت.

## 🔧 التطوير

لا توجد خطوة بناء ولا تبعيات في الإضافة نفسها — جافاسكريبت نمطية خالصة. أدوات التطوير في `dist` (اختبارات الوحدة والتكامل والمتصفح الحقيقي وإمكانية الوصول، مع فحص الأنواع):

```bash
cd dist
pnpm test                                    # unit + integration tests (no browser needed)
pnpm install                                 # dev tooling: Puppeteer, TypeScript, axe-core
pnpm typecheck                               # tsc --checkJs over the extension
pnpm exec puppeteer browsers install chrome  # one-time: download Chrome for Testing
pnpm test:e2e                                # real-browser tests
pwsh build.ps1                               # builds the upload zip from extension/
```

للاطلاع على البنية المعمارية ونموذج البيانات وخريطة الملفات راجع **[CLAUDE.md](CLAUDE.md)**؛ وللمساهمة (أو إضافة لغة) راجع **[CONTRIBUTING.md](CONTRIBUTING.md)**.

## 📁 البنية

```
extension/               ← the shippable extension (load/upload this folder)
  manifest.json          — extension config (MV3)
  _locales/              — name, description and shortcut labels per language (Web Store listing)
  background.js          — the tracking engine (service worker)
  src/lib/                — shared logic (storage, stats, charts, backup, crypto, i18n)
  src/lib/locales/        — UI languages (JSON, one file each)
  src/popup/               — the quick popup
  src/dashboard/            — the full dashboard
  src/blocked/              — the focus-mode block page
  icons/                  — icons
store-assets/            ← store assets: privacy policy, listing copy, images
  site/                  — marketing website source (published to GitHub Pages)
dist/                    ← dev tooling: tests, package.json, build.ps1, and the built zip
archive/                 ← superseded assets (old images/build versions)
```

## 🔒 الأذونات وسبب الحاجة إليها

| الإذن | الاستخدام |
|---|---|
| `storage` / `unlimitedStorage` | تخزين بيانات الوقت والإعدادات محليًا |
| `tabs` | تحديد نطاق التبويب النشط |
| `idle` | إيقاف العدّ أثناء عدم النشاط |
| `alarms` | الحفظ الدوري والنسخ الاحتياطي التلقائي |
| `notifications` | تنبيهات حدود الوقت |
| `favicon` (اختياري) | أيقونات مواقع حقيقية من ذاكرة التخزين المؤقت المحلية لـ Chrome — فقط عند التفعيل يدويًا |

لا يوجد إذن `host`، ولا وصول إلى محتوى الصفحة — فقط اسم النطاق.
