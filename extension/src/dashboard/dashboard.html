ברוך הבא ל-TimeTrack 👋

התוסף יתחיל למדוד את זמן הגלישה הפעיל שלך באופן אוטומטי. כל הנתונים נשמרים מקומית במחשב שלך בלבד.

  • 📊 פילוח חכם לפי קטגוריות וציון פוקוס
  • 🎯 יעדים, מגבלות ומצב פוקוס
  • ☁️ גיבוי בענן מוצפן וייצוא נתונים
